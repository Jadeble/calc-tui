# calc-tui — 终端科学计算器

一个运行在终端中的 TUI 科学计算器。启动后显示一个完整的计算器界面:
左侧为表达式输入、结果与历史记录,右侧为帮助面板与组合按键说明。

> 版本 v0.2.1  ·  发布者 JADE  ·  2026.08.08  ·  [更新日志](CHANGELOG.md)

## 功能特性

- **基本运算**: 加减乘除、乘方 `x^y`、取模、隐式乘法(`2pi`、`2(3+4)`、`2sin(x)` 自动补乘号,支持科学计数法 `2e3`)
- **复数运算**: 虚数单位 `i`、`a+bi` 结果显示(`e^(iπ)` = -1、`sqrt(-1)` = i、`asin(2)` = 1.5708−1.3169i),复数分量/共轭/辐角 `re(z)` `im(z)` `conj(z)` `arg(z)`
- **函数**: 三角函数、反三角函数、双曲函数、余函数 `sec/csc/cot/sech/csch/coth`、`ln`/`log`/`logb(底,x)`/`log2`、`exp`、`sqrt`、阶乘 `n!`、Γ 函数 `gamma(x)`、组合/排列 `C(n,k)` `A(n,k)`、统计 `mean/var/std`、`frac(x)`、`round(x,n)`
- **高级运算**: 求和 `Σ(k,1,10,k^2)`、定积分 `∫(x,0,1,x^2)`、求导 `deriv(x^2,x,2)`,三者可任意嵌套;上下限为 `∞` 时支持收敛级数与瑕积分
- **自定义函数**: 底部输入框自动命名 `f_1(x)=` 保存即用,函数体支持任意表达式组合与互相调用;输入 `f` 自动弹出函数下拉列表
- **角度/弧度切换**: `Tab` 一键切换,`30°` 写法两种模式均正确
- **组合按键输入**: 无法直接键入的符号用 `\p`、`\s` 等组合输入即替换,`F2` 进入设置界面可自由修改、添加、删除(预设组合标注"固定",可改按键不可删除)
- **表达式历史**: `↑`/`↓` 回看,`Enter` 计算

## 安装

### 方式一:下载 Release 二进制

从 [Releases](https://github.com/Jadeble/calc-tui/releases) 下载对应平台的裸二进制(直接可运行,无需解压):

| 平台 | 文件名 |
|---|---|
| Linux x86_64(静态链接,不依赖 glibc) | `calc-tui-x86_64-linux-musl` |
| Linux ARM64(静态链接) | `calc-tui-aarch64-linux-musl` |
| macOS Apple Silicon | `calc-tui-aarch64-macos` |
| macOS Intel | `calc-tui-x86_64-macos` |
| Windows x86_64 | `calc-tui-x86_64-windows.exe` |

Linux 产物使用 musl 静态编译,不依赖系统 glibc 版本,在各类 Linux 发行版(含旧版本系统)均可直接运行:

```bash
chmod +x calc-tui-x86_64-linux-musl
./calc-tui-x86_64-linux-musl
```

### 方式二:源码构建

需要 Rust 工具链(1.75+):

```bash
git clone https://github.com/Jadeble/calc-tui.git
cd calc-tui
cargo build --release
./target/release/calc-tui
```

也可以直接 `cargo run --release` 运行。项目附带的 `run.sh` 会在检测到的默认终端中启动计算器。

## 使用说明

| 按键 | 功能 |
|---|---|
| `Enter` | 计算 |
| `Tab` | 切换 角度(DEG) / 弧度(RAD) |
| `Ctrl+F` | 切换输入焦点(表达式 / 自定义函数) |
| `F2` | 设置(组合按键 / 自定义函数) |
| `↑` / `↓` | 历史记录回看 |
| `Esc` | 输入非空时清空,为空时退出 |
| `Ctrl+C` | 强制退出 |

### 组合按键(输入即替换)

| 组合 | 插入 | 组合 | 插入 |
|---|---|---|---|
| `\p` | π | `\d` | deriv( |
| `\s` | Σ( | `\r` | √( |
| `\i` | ∫( | `\x` | × |
| `\v` | ÷ | `\e` | e |

按 `F2` 可编辑/添加/删除组合按键,修改后自动保存到 `~/.config/calc-tui/config.json`。
预设组合(π/Σ/∫/deriv/√/φ,因键盘无法直接键入)标注"固定",可修改按键但不能删除。

### 自定义函数

主窗口底部是自定义函数输入框(前缀 `f_n(x)=` 自动命名),输入函数体后按 `Enter` 保存,
例如输入 `x+1` 保存为 `f_1(x)=x+1`,之后表达式里可直接使用 `f_1(2)` = 3。

- 函数体支持任意表达式组合: `sin(x)^2`、`Σ(k,1,3,k*x)`、`∫(t,0,x,t^2)`、`deriv(t^2,t,x)` 等
- 输入 `f` 时自动弹出函数下拉列表,`↑`/`↓` 选择、`Enter` 插入函数名(表达式框和函数体框均可,`Esc` 关闭)
- 函数之间可互相调用: `f_1(x)=f_2(x)+1`;自引用或循环引用会报"嵌套过深"
- 删除函数不会重编号,新函数优先复用最小空闲编号
- 按 `F2` 进入设置,`←`/`→` 切换到"自定义函数"标签可查看/编辑/删除;
  删除被其他函数引用的函数会被拦截并提示引用者

### 公式语法

- **复数**: `i` 为虚数单位,结果自动显示 `a+bi`(`e^(iπ)` = -1、`sqrt(-1)` = i、`asin(2)` = 1.5708−1.3169i)
  - 复数分量/共轭/辐角: `re(z)` `im(z)` `conj(z)` `arg(z)`;`abs(z)` 为模
- **函数**: `sin` `cos` `tan` `asin` `acos` `atan` `sinh` `cosh` `tanh` `ln` `log`(底 10) `logb(底,x)` `log2` `sqrt` `exp` `n!` `gamma(x)`(Γ 函数) `sec` `csc` `cot` `sech` `csch` `coth` `frac(x)` `round(x,n)`
- **组合/排列**: `C(n,k)` `A(n,k)` → `C(5,2)` = 10
- **统计**: `mean(1,2,3,4)` = 2.5、`var(1,2,3,4)` = 1.25、`std(x,…)` = √var;`max(x,…)` `min(x,…)`
- **常量**: `π` `e` `φ` `g` `i` `ln2` `ln10` `sqrt2` `γ`(欧拉常数,直接键入 γ)
- **求和**: `Σ(变量, 起始, 结束, 表达式)` → `Σ(k,1,10,k^2)` = 385;结束为 `∞` 时按收敛级数求和(`Σ(k,1,∞,1/k²)` ≈ 1.6449)
- **定积分**: `∫(变量, 下限, 上限, 表达式)` → `∫(x,0,1,x^2)` ≈ 0.3333;上限/下限为 `∞` 时按瑕积分处理(`∫(x,1,∞,1/x²)` = 1)
- **求导**: `deriv(表达式, 变量, 取值点)` → `deriv(x^2,x,2)` = 4
- **嵌套**: `Σ(k,1,3,∫(x,0,k,x^2))` = 12
- **角度**: DEG 模式下 `sin(30)` = 0.5;两种模式下 `sin(30°)` 均 = 0.5
- 结果范围受双精度浮点限制(约 1.8×10³⁰⁸),`171!` 等溢出显示为 `∞`

## 技术栈

- [ratatui](https://github.com/ratatui/ratatui) — TUI 渲染
- [crossterm](https://github.com/crossterm-rs/crossterm) — 终端事件
- `src/expr.rs` — 自研表达式解析求值(分词 + 调度场算法)
- `src/complex.rs` — 自研复数运算(主分支约定,实参走 f64 精确路径)
