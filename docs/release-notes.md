# calc-tui v0.2.3 — 终端科学计算器(Linux 版)

基于 Rust + ratatui 的 TUI 科学计算器,启动即显示完整计算器界面:
左侧为表达式输入、结果与历史记录,ctrl+h打开右侧的帮助面板与组合按键说明。

> 自本版本起,项目仅构建并发布 Linux 平台(musl 静态编译),不再发布 Windows / macOS 版本。

## 功能

- **基本运算**: 加减乘除、乘方 `x^y`、取模、隐式乘法(`2pi`、`2(3+4)`、`2sin(x)` 自动补乘号)、科学计数法(`2e3`)
- **复数运算**: 虚数单位 `i`,结果自动显示 `a+bi`(`e^(iπ)` = -1、`sqrt(-1)` = i、`asin(2)` = 1.5708−1.3169i)
  - 全部内置函数支持复数(主分支约定):`sin` `cos` `tan` `asin` `acos` `atan` `sinh` `cosh` `tanh` `asinh` `acosh` `atanh` `sqrt` `exp` `ln` `log` `log2` `log10` `logb`
  - 复数分量/共轭/辐角: `re(z)` `im(z)` `conj(z)` `arg(z)`;`abs(z)` 为模;DEG 角度模式同样支持复数
- **函数**: 三角/反三角/双曲函数、余函数 `sec` `csc` `cot` `sech` `csch` `coth`、`ln`/`log`/`logb(底,x)`/`log2`、`exp`、`sqrt`、阶乘 `n!`、Γ 函数 `gamma(x)`(Lanczos 近似)、`frac(x)`、`round(x,n)`
- **组合/排列**: `C(n,k)` `A(n,k)`(乘法公式,大数不中间溢出)→ `C(5,2)` = 10
- **统计函数**(变参): `mean(x,…)` 均值、`var(x,…)` 总体方差、`std(x,…)` 标准差、`max(x,…)` `min(x,…)`
- **高级运算**: 求和 `Σ(k,1,10,k^2)`、定积分 `∫(x,0,1,x^2)`、求导 `deriv(x^2,x,2)`,三者可任意嵌套(`Σ(k,1,3,∫(x,0,k,x^2))` = 12)
  - 上下限为 `∞` 时:收敛级数 `Σ(k,1,∞,1/k²)` ≈ 1.6449、瑕积分 `∫(x,1,∞,1/x²)` = 1(环带累加,宽区间高效收敛);发散级数明确报"未收敛"
- **自定义函数**: 主窗口底部输入框自动命名 `f_1(x)=` 保存即用,函数体支持任意表达式组合与函数互相调用;输入 `f` 自动弹出函数下拉列表(`↑`/`↓` 选择、`Enter` 插入);删除被引用函数会拦截提示;持久化到配置文件,重启保留
- **角度/弧度切换**: `Tab` 一键切换,DEG 模式下 `sin(30)` = 0.5;`30°` 写法两种模式均正确
- **组合按键输入**: 无法直接键入的符号用 `\p`→π、`\s`→Σ(、`\i`→∫(、`\d`→deriv(、`\r`→√(、`\x`→×、`\v`→÷、`\e`→e 输入即替换;`F2` 进入设置界面可自由修改、添加、删除
- **表达式历史**: `↑`/`↓` 回看,`Enter` 计算

## 安装

从 [Releases](https://github.com/Jadeble/calc-tui/releases) 下载对应架构的裸二进制(直接可运行,无需解压):

| 平台 | 文件名 |
|---|---|
| Linux x86_64 | `calc-tui-x86_64-linux-musl` |
| Linux ARM64 | `calc-tui-aarch64-linux-musl` |

Linux 产物使用 musl 静态编译,不依赖系统 glibc 版本,在各类 Linux 发行版(含旧版本系统)均可直接运行:

```bash
chmod +x calc-tui-x86_64-linux-musl
./calc-tui-x86_64-linux-musl
```

## 快捷键

| 按键 | 功能 |
|---|---|
| `Enter` | 计算 |
| `Tab` | 切换 角度(DEG) / 弧度(RAD) |
| `Ctrl+F` | 切换输入焦点(表达式 / 自定义函数) |
| `F2` | 设置(组合按键 / 自定义函数) |
| `↑` / `↓` | 历史记录回看 |
| `Esc` | 输入非空时清空,为空时退出 |
| `Ctrl+C` | 强制退出 |
